## 2. 計測（Cookie を使わない）

| 候補 | 無料の範囲 | 商用 | 端末に保存 | 判定 |
|---|---|---|---|---|
| GoatCounter | 「適度な公開利用は無料」、有料プランなし（寄付で運営） | 個人サイト・中小事業は可（規約。親が照合） | Cookie・localStorage なし | 第 1 候補。1 行で入る、約 3.5KB。広告ブロッカーで少なめに出る |
| Umami Cloud Hobby | 月 10 万イベント・1 サイト・6 か月保存 | 未確認 | 未確認 | 第 2 候補（規約の確認が要る） |
| Cloudflare Web Analytics | 無料 | 有力 | なし | 「今は Cloudflare を使わない」方針と合わない |

- 外部送信規律（改正電気通信事業法）: 個人運営の無料ツールはおそらく対象外（総務省 FAQ では対象は 4 種類の役務に限られる。ツール型サイトの明示例は無く推測）。念のため「表示回数を数えるために GoatCounter を使っています。Cookie は使わず、画像は送信しません」と画面に書く

## 3. 寄付

| 受け取り方 | 1,000 円の手取り（出金前） | 出金 1 回の手数料 | 10 件まとめて出金 | 向き・注意 |
|---|---:|---:|---:|---|
| OFUSE 単発 | 840 円 | 275 円 | 8,125 円 | 日本語・国内銀行・Web サービス運営者も対象。手数料の数字は codex の調査のみ（公式ヘルプが 403 で親は未照合） |
| Ko-fi（PayPal 経由） | 924 円 | 250 円 | 8,990 円 | 手数料は低めだが、PayPal の取引区分しだい。英語中心 |
| GitHub Sponsors | 1,000 円相当（米ドル） | 為替で不明 | 約 10,000 円相当 | 個人からは 100%。ただし **オープンソースとして公開していることが条件**。支援者に GitHub アカウントが要る |

- 税: 「寄付」という名前でも贈与税で済むとは限らない。アプリ等の収入は原則として事業所得か雑所得（国税庁）。受取日・総額・手数料・出金額を記録しておき、迷ったら税務署に確認する
- 特商法: 見返りの無い完全任意の支援なら通常は通信販売に当たらない見込み。有料機能（200 枚超など）を売るときは表示（氏名・住所・電話。省略は「請求があれば遅滞なく開示」の措置が条件）が要る
- 支援者に寄附金控除を案内しない（対象は国・自治体・特定の公益法人など）

## 4. ライセンス（判断材料）

| 選択肢 | 他人のコピー・競合 | 後で有料版を作る | 寄付との関係 |
|---|---|---|---|
| ライセンスを付けない（権利を保持） | 許可が無いので使えない（ただし配信される JS は誰でも読める） | 自由。後から MIT にもできる | GitHub Sponsors は使えない（OSS ではない） |
| MIT | 表示さえ残せば自由に使える | できるが、公開済みの版は MIT のまま取り消せない | GitHub Sponsors が使える |
| ソースを見せて商用を制限（PolyForm Noncommercial など） | 非商用だけ許す | 自分は自由 | OSS ではないので GitHub Sponsors は使えない |

- どれを選んでも、依存（React・Vite・fflate など MIT）の著作権表示は配信物に載せる。ビルドでコメントが消えるので、`THIRD-PARTY-NOTICES` を別ファイルにして画面の下からリンクする
- 法的な断定はしない。迷ったら専門家に確認

## 5. 無料で扱える枚数
- 技術の上限は 1 回 500 枚（04 ③）。初版は全部無料なので、500 枚まで無料
- 有料化するときの候補: 1 回 200 枚を超える処理と設定の保存を買い切り。そのときは GitHub Pages では売れないので公開先を移す（無料プランで商用可と明示された先は見つからず。Cloudflare・Netlify は禁止の条文が無いだけで、可の明示も無い）
